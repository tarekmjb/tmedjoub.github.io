About

From Network Operations to Project Delivery

My core skills cover Cisco routing and switching, Fortinet security and multisite connectivity. I work with VLAN segmentation, OSPF/BGP routing, firewall policies, NAT and IPsec VPNs. My experience also includes Fortinet SD-WAN, redundant links and high-availability architectures.

My hybrid cloud work focuses on connecting on-premises networks to Azure VPN Gateway and AWS Transit Gateway through IPsec tunnels and BGP route exchange, with centralized PRTG monitoring. These laboratory projects complement my production experience in networking and security.

I use Zabbix, PRTG and GLPI to monitor infrastructure, investigate connectivity issues and track incidents. Alongside configuration and troubleshooting, I contribute to technical audits, architecture documentation and project coordination. I continue developing my skills through EVE-NG labs in routing, security, hybrid cloud connectivity and Ansible automation.
