VLAN & routage inter-VLAN

Segmenter les utilisateurs en VLAN, les transporter sur un trunk sécurisé, puis les router de deux façons : SVI sur un commutateur de niveau 3, puis router-on-a-stick.

Objectif

Segmenter les utilisateurs en VLAN, les transporter sur un trunk sécurisé, puis les router de deux façons : SVI sur un commutateur de niveau 3, puis router-on-a-stick.

Prérequis

  • EVE-NG (Community ou Pro) avec les images indiquées dans la topologie.
  • Accès console à chaque nœud ; bases de la CLI.

Topologie & adressage

ÉquipementInterfaceAdresse / rôle
VLAN 10Users10.10.10.0/24 · gw .1
VLAN 20Voice / Lab10.10.20.0/24 · gw .1
VLAN 99Native (unused)—

Construction pas à pas

1. Créer les VLAN et les ports d’accès

Mêmes ID de VLAN sur les deux commutateurs.

ASW1
vlan 10
 name USERS
vlan 20
 name VOICE
vlan 99
 name NATIVE-UNUSED
!
interface Gi0/1
 switchport mode access
 switchport access vlan 10
interface Gi0/2
 switchport mode access
 switchport access vlan 20

2. Construire un trunk sécurisé

Trunk statique, liste autorisée explicite, VLAN natif inutilisé, pas de DTP.

ASW1 / DSW1
interface Gi0/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 switchport nonegotiate

3. Router avec des SVI

Commutateur L3 : une SVI par VLAN, et activer le routage.

DSW1
ip routing
!
interface Vlan10
 ip address 10.10.10.1 255.255.255.0
 no shutdown
interface Vlan20
 ip address 10.10.20.1 255.255.255.0
 no shutdown

4. Variante : router-on-a-stick

Supprimer les SVI et router sur des sous-interfaces de R1.

R1
interface Gi0/0.10
 encapsulation dot1Q 10
 ip address 10.10.10.1 255.255.255.0
interface Gi0/0.20
 encapsulation dot1Q 20
 ip address 10.10.20.1 255.255.255.0
interface Gi0/0.99
 encapsulation dot1Q 99 native

Vérifier

CommandeCe que vous devez voir
show vlan briefPorts d’accès dans le bon VLAN.
show interfaces trunkTrunk actif, natif 99, autorisés 10,20,99.
show ip interface brief | include VlanSVI up/up.
ping 10.10.20.11 (from PC-10)Réponses via la passerelle.

Casser, puis réparer

Introduisez chaque panne, observez le symptôme, puis ouvrez l’indice.

panneVLAN absent de la liste autorisée

Les hôtes de ce VLAN ne joignent pas leur passerelle. Vérifier show interfaces trunk.

panneVLAN natif différent

CDP signale un native VLAN mismatch et le trafic non tagué fuit entre VLAN.

panneLa SVI reste down

Une SVI n’est up que si un port de ce VLAN est actif (accès ou trunk).

À retenir

  • Un VLAN est un domaine de diffusion ; c’est le routage qui les relie.
  • Un trunk doit être explicite : liste autorisée, VLAN natif, pas de DTP.
  • Les SVI passent mieux à l’échelle que le router-on-a-stick, qui partage un seul lien pour tous les VLAN.
