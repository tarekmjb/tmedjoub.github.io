Contexte & objectifs

Les seuils et la configuration ci-dessous sont des valeurs représentatives de cette conception, données à titre d’illustration.

Dans un réseau multisite, le problème n’est pas le manque d’alertes, mais trop d’e-mails, sans responsable ni historique. L’objectif : transformer la supervision en processus d’incident. Détecter, ouvrir un ticket, affecter, résoudre, et clôturer automatiquement quand le problème disparaît.

Architecture

collecteZabbix + SNMPv3authPriv (SHA / AES) sur chaque équipement réseau ; agents sur les serveurs. Modèles par famille d’équipements.
WAN & cloudPRTGCapteurs ping, SNMP et HTTP sur les liens FAI, tunnels IPsec et points d’accès cloud.
incidentGLPIUn webhook crée le ticket via l’API REST de GLPI, avec hôte, sévérité et lien vers le graphe. Le retour à la normale ajoute un suivi et le clôture.
anti-bruitDépendances & hystérésisSi le routeur d’un site tombe, les alertes des équipements derrière lui sont supprimées. Les seuils de retour sont plus bas que les seuils de déclenchement pour éviter les oscillations.

Expressions de déclencheurs Zabbix (syntaxe 6.x)
# Interface saturation, with hysteresis via recovery expression
avg(/FG-SITE-A/net.if.in[ifHCInOctets.5],10m) > 0.9 * last(/FG-SITE-A/net.if.speed[ifHighSpeed.5])
# recovery:
avg(/FG-SITE-A/net.if.in[ifHCInOctets.5],10m) < 0.75 * last(/FG-SITE-A/net.if.speed[ifHighSpeed.5])

# Device unreachable: 3 consecutive ICMP failures
max(/FG-SITE-A/icmpping,#3) = 0

Les clés d’items sont simplifiées pour la lecture ; en pratique elles proviennent des modèles constructeur.

Processus d’incident

Détecter

Un déclencheur s’active dans Zabbix (ou un capteur passe en erreur dans PRTG).

Ouvrir

Le webhook crée un ticket GLPI : catégorie, priorité selon la sévérité, hôte, dernières valeurs et lien vers le graphe.

Affecter & acquitter

Le ticket part au groupe réseau ; l’acquittement dans Zabbix stoppe l’escalade.

Résoudre

Quand le déclencheur revient à la normale, un suivi est ajouté et le ticket est résolu automatiquement.

Analyser

Revue hebdomadaire des tickets récurrents pour traiter les causes, pas les symptômes.

Configuration côté équipements

Cisco IOS · SNMPv3 authPriv
snmp-server group NMS v3 priv read NMS-VIEW access ACL-NMS
snmp-server view NMS-VIEW iso included
snmp-server user zabbix NMS v3 auth sha <redacted> priv aes 128 <redacted>
snmp-server host 10.10.50.20 version 3 priv zabbix
snmp-server enable traps snmp linkdown linkup
!
ip access-list standard ACL-NMS
 permit 10.10.50.20
FortiOS · SNMPv3
config system snmp user
    edit "zabbix"
        set notify-hosts 10.10.50.20
        set security-level auth-priv
        set auth-proto sha256
        set auth-pwd ENC ********
        set priv-proto aes256
        set priv-pwd ENC ********
    next
