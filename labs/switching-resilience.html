STP & LACP resilience

Make a looped switch triangle predictable: Rapid PVST+ with a planned root per VLAN, an LACP bundle between the distribution switches, and guards that protect the topology at the edge.

Objective

Make a looped switch triangle predictable: Rapid PVST+ with a planned root per VLAN, an LACP bundle between the distribution switches, and guards that protect the topology at the edge.

Prerequisites

  • EVE-NG (Community or Pro) with the images listed in the topology.
  • Console access to every node; basic CLI knowledge.

Topology & addressing

DeviceInterfaceAddress / role
DSW1 ↔ DSW2Gi0/1–2 → Po1trunk 10,20
DSW1 / DSW2 → ASW1Gi0/3trunk 10,20
ASW1Gi1/0–3access VLAN 10 / 20

Build it step by step

1. Rapid PVST+ and root placement

Split roots per VLAN to use both uplinks.

DSW1
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary
spanning-tree vlan 20 root secondary

2. LACP bundle

Members must share speed, duplex and trunk settings.

DSW1 / DSW2
interface range GigabitEthernet0/1 - 2
 switchport trunk encapsulation dot1q
 switchport mode trunk
 channel-group 1 mode active
!
interface Port-channel1
 switchport trunk allowed vlan 10,20

3. Edge protection

PortFast + BPDU Guard on access ports, Root Guard on distribution ports facing access.

ASW1 / DSW1
! ASW1 access ports
interface range GigabitEthernet1/0 - 3
 spanning-tree portfast
 spanning-tree bpduguard enable
! DSW1 downlink to ASW1
interface GigabitEthernet0/3
 spanning-tree guard root
!
errdisable recovery cause bpduguard
errdisable recovery interval 300

Verify

CommandWhat you should see
show spanning-tree vlan 10DSW1 is root; one ASW1 uplink is Alternate/Blocking.
show etherchannel summaryPo1(SU) with members (P).
show lacp neighborPartner seen on both members.
show spanning-tree inconsistentportsEmpty in normal operation.

Break it, then fix it

Introduce each fault, observe the symptom, then open the hint.

breakmode on vs mode active

No bundle; members suspended. Use LACP active (or passive) on both sides.

breakRogue switch on an access port

BPDU Guard puts the port err-disabled. Check show interfaces status err-disabled.

breakBetter priority announced from access

Root Guard blocks it: the port goes root-inconsistent instead of moving the root.

Key takeaways

  • Never let STP elect the root by accident: place it.
  • LACP negotiates; mode on hides mistakes.
  • Guards turn edge mistakes into a single err-disabled port instead of an outage.
