VLANs & inter-VLAN routing

Objective

Segment users into VLANs, carry them over a secured trunk, and route between them twice: first with SVIs on a layer-3 switch, then with router-on-a-stick.

Prerequisites

  • EVE-NG (Community or Pro) with the images listed in the topology.
  • Console access to every node; basic CLI knowledge.

Topology & addressing

DeviceInterfaceAddress / role
VLAN 10Users10.10.10.0/24 · gw .1
VLAN 20Voice / Lab10.10.20.0/24 · gw .1
VLAN 99Native (unused)—

Build it step by step

1. Create VLANs and access ports

Same VLAN IDs on both switches.

ASW1
vlan 10
 name USERS
vlan 20
 name VOICE
vlan 99
 name NATIVE-UNUSED
!
interface Gi0/1
 switchport mode access
 switchport access vlan 10
interface Gi0/2
 switchport mode access
 switchport access vlan 20

2. Build a secure trunk

Static trunk, explicit allowed list, unused native VLAN, no DTP.

ASW1 / DSW1
interface Gi0/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 switchport nonegotiate

3. Route with SVIs

Layer-3 switch: one SVI per VLAN, and enable routing.

DSW1
ip routing
!
interface Vlan10
 ip address 10.10.10.1 255.255.255.0
 no shutdown
interface Vlan20
 ip address 10.10.20.1 255.255.255.0
 no shutdown

4. Variant: router-on-a-stick

Remove the SVIs and route on R1 sub-interfaces instead.

R1
interface Gi0/0.10
 encapsulation dot1Q 10
 ip address 10.10.10.1 255.255.255.0
interface Gi0/0.20
 encapsulation dot1Q 20
 ip address 10.10.20.1 255.255.255.0
interface Gi0/0.99
 encapsulation dot1Q 99 native

Verify

CommandWhat you should see
show vlan briefAccess ports in the right VLAN.
show interfaces trunkTrunking, native 99, allowed 10,20,99.
show ip interface brief | include VlanSVIs up/up.
ping 10.10.20.11 (from PC-10)Replies through the gateway.

Break it, then fix it

Introduce each fault, observe the symptom, then open the hint.

breakVLAN missing from the allowed list

Hosts in that VLAN can’t reach their gateway. Check show interfaces trunk.

breakNative VLAN mismatch

CDP logs a native VLAN mismatch and untagged traffic leaks between VLANs.

breakSVI stays down

An SVI is only up if one port in that VLAN is up (access or trunk).

Key takeaways

  • A VLAN is a broadcast domain; routing is what joins them.
  • Trunks should be explicit: allowed list, native VLAN, no DTP.
  • SVIs scale better than router-on-a-stick, which shares one link for all VLANs.
