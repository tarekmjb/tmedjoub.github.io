# EVE-NG Labs publication guide

Labs are protocol-focused learning exercises, separate from the portfolio’s architecture projects.

The BGP, OSPF, VLAN and IPsec outlines are marked Planned. Before publishing a completed lab:
1. State objectives, prerequisites, device versions and image requirements.
2. Add the topology and addressing plan.
3. Add tested configurations with explanations.
4. Record verification commands, real outputs and troubleshooting scenarios.
5. Add the EVE-NG .unl or export file and captures. Do not redistribute vendor images.
6. Update the page and homepage status only after validating the lab.

The English HTML pages can be edited directly. Add a new card under #labs for each new tutorial.
