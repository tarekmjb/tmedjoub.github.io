SNMPv3 monitoring with Zabbix

Secure SNMP with v3 authPriv on a switch, test it from the Zabbix server with snmpwalk, add the device with a vendor template and fire a trigger by shutting an interface.

Objective

Secure SNMP with v3 authPriv on a switch, test it from the Zabbix server with snmpwalk, add the device with a vendor template and fire a trigger by shutting an interface.

Prerequisites

  • EVE-NG (Community or Pro) with the images listed in the topology.
  • Console access to every node; basic CLI knowledge.

Topology & addressing

DeviceInterfaceAddress / role
Zabbix servereth010.10.50.20/24
SW1Vlan50 (mgmt)10.10.50.2/24

Build it step by step

1. SNMPv3 on the switch

authPriv (SHA + AES), read-only view, and an ACL so only Zabbix can poll.

SW1
ip access-list standard ACL-NMS
 permit 10.10.50.20
!
snmp-server view NMS-VIEW iso included
snmp-server group NMS v3 priv read NMS-VIEW access ACL-NMS
snmp-server user zabbix NMS v3 auth sha <redacted> priv aes 128 <redacted>
snmp-server host 10.10.50.20 version 3 priv zabbix
snmp-server enable traps snmp linkdown linkup

2. Test from the server

If snmpwalk fails, Zabbix will too. Fix it here first.

Zabbix server
snmpwalk -v3 -l authPriv -u zabbix \
  -a SHA -A '<auth-pass>' -x AES -X '<priv-pass>' \
  10.10.50.2 1.3.6.1.2.1.1

3. Add the host in Zabbix

Data collection → Hosts → Create host: SNMP interface 10.10.50.2, SNMPv3 authPriv credentials, template for the vendor (for example Cisco IOS by SNMP).

Zabbix UI
Host name      : SW1
Interface      : SNMP 10.10.50.2:161
SNMP version   : SNMPv3
Security level : authPriv
Auth / Priv    : SHA / AES
Template       : Cisco IOS by SNMP

Verify

CommandWhat you should see
snmpwalk … 1.3.6.1.2.1.1sysDescr, sysName and sysUpTime returned.
Zabbix → Monitoring → Latest dataInterface and CPU items updating.
shutdown Gi0/5 on SW1Link down problem appears in Zabbix within the polling interval.
no shutdownProblem resolves automatically.

Break it, then fix it

Introduce each fault, observe the symptom, then open the hint.

breakWrong auth or priv password

snmpwalk returns an authentication failure or decryption error. Re-create the user.

breakACL doesn’t include the server

Timeouts only. Check the ACL hit counters.

breakSecurity level mismatch

Zabbix set to authNoPriv against a priv user: no data. Align on authPriv.

Key takeaways

  • SNMPv1/v2c send the community in clear text; use v3 authPriv.
  • Always prove SNMP with snmpwalk before blaming the monitoring tool.
  • Start from vendor templates, then tune triggers to cut noise.
