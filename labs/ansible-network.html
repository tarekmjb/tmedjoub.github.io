Ansible network automation

Use Ansible to back up every router configuration, push a standard NTP and logging baseline, and prove the change is idempotent with check mode.

Objective

Use Ansible to back up every router configuration, push a standard NTP and logging baseline, and prove the change is idempotent with check mode.

Prerequisites

  • EVE-NG (Community or Pro) with the images listed in the topology.
  • Console access to every node; basic CLI knowledge.

Topology & addressing

DeviceInterfaceAddress / role
Ansible hosteth010.99.0.5/24
R1–R3Gi0/3 (mgmt)10.99.0.11–13/24

Build it step by step

1. Inventory

Group the routers and set the network connection. The password comes from Ansible Vault.

inventory.yml
all:
  children:
    ios:
      hosts:
        r1: { ansible_host: 10.99.0.11 }
        r2: { ansible_host: 10.99.0.12 }
        r3: { ansible_host: 10.99.0.13 }
      vars:
        ansible_network_os: cisco.ios.ios
        ansible_connection: ansible.netcommon.network_cli
        ansible_user: netadmin
        ansible_password: "{{ vault_ios_password }}"
        ansible_become: true
        ansible_become_method: enable

2. Back up configurations

One file per device in ./backups.

backup.yml
- name: Backup running configs
  hosts: ios
  gather_facts: false
  tasks:
    - name: Save running-config
      cisco.ios.ios_config:
        backup: true
        backup_options:
          dir_path: ./backups
          filename: "{{ inventory_hostname }}.cfg"

3. Push a baseline

Only missing lines are sent. Save the config only if something changed.

baseline.yml
- name: NTP and logging baseline
  hosts: ios
  gather_facts: false
  tasks:
    - name: Ensure NTP and syslog
      cisco.ios.ios_config:
        lines:
          - ntp server 10.99.0.1
          - logging host 10.99.0.20
          - service timestamps log datetime msec
        save_when: changed

Verify

CommandWhat you should see
ansible-playbook -i inventory.yml backup.ymlOne .cfg per router in ./backups.
ansible-playbook -i inventory.yml baseline.yml --check --diffShows the lines that would be added, changes nothing.
ansible-playbook -i inventory.yml baseline.yml (run twice)Second run: changed=0 (idempotent).
ansible ios -i inventory.yml -m cisco.ios.ios_command -a "commands='show run | i ntp'"NTP line present on every router.

Break it, then fix it

Introduce each fault, observe the symptom, then open the hint.

breakUnknown SSH host key

Connection refused on first run. Add the keys to known_hosts (do not disable checking in production).

breakPrivilege level too low

Config commands fail. Set become with method enable.

breakLine written differently on the device

Task reports changed every run. Match the exact running-config syntax.

Key takeaways

  • Back up before you automate changes.
  • Check mode with diff is your change review.
  • Idempotence (changed=0 on rerun) proves the playbook describes a state, not a script.
